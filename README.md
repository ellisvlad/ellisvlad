# Vlad Ellis

Hi, I'm EllisVlad. I like to build cool projects and turn my side projects into puzzles, like the snake game above, written
with SVG + CSS animations, and no JavaScript. My git is private and self-hosted at [git.co.nr](https://git.co.nr), but snake
is playing over my live git commit graph and is rebuilt every day. More at [git.co.nr/ellisvlad](https://git.co.nr/ellisvlad/).

## Inspiration

The idea for building the snake above came from [David Liu's GitHub profile](https://github.com/dahan8473), which he noted was
itself inspired by the contribution-graph art tradition ([Platane/snk](https://github.com/Platane/snk) and friends). I also
rebuilt it from scratch as a game engine/library with multiple games and various smart AI players at [git.co.nr/ellisvlad](https://git.co.nr/ellisvlad/).
