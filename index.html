Hi, I'm EllisVlad. I like to build cool projects and turn my side projects into puzzles, like the snake game above, written with SVG + CSS animations, and no JavaScript. My git is private and self-hosted at git.co.nr, but snake is playing over my live git commit graph and is rebuilt every day. More at git.co.nr/ellisvlad.

Take a look around

Each of the SVG above is automatically regenerated daily from my commit graph. Each game is pre-simulated and optimized for both an entertaining watch and clever gameplay. For example, the snake AI is trained to hunt down commits in a deliberately challenging pattern, and can plan ahead paths considering where its body will be by the time is gets there, so it can never trap itself in a corner.

There are also a bunch of other games using this same "commit svg game engine". Every game is pre-baked with a simulation seeded by the date, and replay is optimized to squeeze into a single SVG with no JavaScript.

If you want to try making something similar; it is a fun challenge to work on, and I invite anyone that thinks they can do better to build their own commit-graph snake, then come back and compare. See if you can solve in fewer moves, or with smaller files, or cleverer AI. I'd love to see it. Send me an email; it's on this page.
